# Напоминания о приёме таблеток: управляемый промпт с JSON-ответом

Пользователь пишет расписание приёма своими словами, модель возвращает **валидный JSON** с планом напоминаний на день:

```json
{
  "title": "План приёма на день: витамин D и магний",
  "steps": ["09:00 — Витамин D, 1 таблетка, после еды", "21:00 — Магний, 1 таблетка, перед сном"],
  "notes": ["Принимайте строго в указанное вами время."]
}
```

Модель не врач: она не назначает препараты и не меняет дозировки и время, а только оформляет расписание, которое указал пользователь.

Учебный проект по курсу «Профессия вайб-кодер» (урок VPf03). Отчёт о сравнении двух версий промпта — в [HOMEWORK.md](HOMEWORK.md).

## Запуск

```bash
pip install openai
export OPENAI_API_KEY=...

# сгенерировать план
python remind.py --version v2 --schedule "Витамин D — 1 таблетка в 09:00 после еды; Магний — 1 таблетка в 21:00 перед сном"

# проверить готовый JSON-ответ (ключ не нужен)
python remind.py --check results/v2_run1.json

# получить настоящие напоминания: план -> файл календаря (ежедневно, со звуком)
python remind.py --check results/v2_run1.json --ics plan.ics
python remind.py --version v2 --schedule "..." --ics plan.ics
```

Файл `plan.ics` открывается на телефоне или в календаре; напоминания придут в 09:00 и 21:00 каждый день.

Параметры: `--version v1|v2`, `--model` (по умолчанию `gpt-4o-mini`), `--temperature` (по умолчанию 0.2). Скрипт собирает `messages` из `prompts/<версия>.json`, вызывает модель и проверяет ответ: валидный JSON, ключи `title`/`steps`/`notes`, формат шага «ЧЧ:ММ — …», не более трёх `notes`.

## Структура

```
prompts/v1.json, v2.json   промпты: базовый и с few-shot примером
results/*.json             сырые ответы: 3 прогона × 2 версии
remind.py                  генерация и проверка
HOMEWORK.md                отчёт по ДЗ
```
